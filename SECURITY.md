## Supported Versions

Security fixes are applied to the latest published release on
[pub.dev](https://pub.dev/packages/tidy_imports). Please always upgrade to the
most recent version before reporting an issue.

| Version | Supported |
|---------|-----------|
| Latest `1.x` | ✅ |
| Older releases | ❌ |

## Reporting a Vulnerability

`tidy_imports` is a developer CLI tool that reads and rewrites Dart source files
and `pubspec.yaml`. If you discover a vulnerability — for example a crafted file
that causes the tool to write outside the project, execute code, or leak data —
please report it privately.

**Preferred:** Use GitHub's
[private vulnerability reporting](https://github.com/Franklyn-R-Silva/tidy_imports/security/advisories/new)
("Report a vulnerability" under the Security tab).

**Alternative:** Email the maintainer at franklyn1998@gmail.com with:

- A description of the vulnerability and its impact
- Steps to reproduce (a minimal sample file is ideal)
- The `tidy_imports` and Dart SDK versions affected

## Response Expectations

- **Acknowledgement:** within 5 business days
- **Assessment & fix timeline:** communicated after triage
- **Disclosure:** coordinated — please give us a reasonable window to release a
  fix before any public disclosure

Thank you for helping keep the Dart community safe.
